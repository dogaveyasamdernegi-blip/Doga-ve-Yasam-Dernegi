# Doga ve Yaşam Derneği - Web Sitesi

Bu depo, Doga ve Yaşam Derneği için basit bir statik web sitesi (Bootstrap tabanlı) içerir.

İçerik:
- index.html — ana sayfa
- styles.css — temel stiller
- assets/ — görseller ve logo (placeholder)

Hızlı kurulum ve GitHub Pages ile yayınlama:
1. Bu depoya zaten erişim sağladığınız için dosyalar main dalına eklendi.
2. GitHub'da repo > Settings > Pages bölümüne gidin ve "Branch: main / (root)" seçeneğini etkinleştirin.
3. GitHub Pages birkaç dakika içinde canlı olacaktır: https://<owner>.github.io/<repo>
